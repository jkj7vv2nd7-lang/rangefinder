# 距離計（単体HTML版）

ライカ式レンジファインダーの「二重像合致」をシミュレーションで練習する、距離当て・ピント練習アプリです。実距離を自動で測るものではありません。`index.html` 1ファイルで動きます（アイコン用に `icon.png` を一緒に置きます）。

## GitHub Pagesでの公開手順
1. GitHubで新しいリポジトリ「rangefinder」を作ります
2. `index.html` と `icon.png` をアップロードします
3. リポジトリの Settings → Pages で、公開するブランチ（main）を選びます
4. 数分待つと公開されます

公開URL： https://jkj7vv2nd7-lang.github.io/rangefinder/

iPhoneのSafariで開いて「ホーム画面に追加」すると、専用アイコンでアプリのように使えます。

## データについて
- フォーカスログは、その端末のブラウザの中にだけ保存されます。サーバーには送られません
- Museライブラリ版とはデータは共有されません（単体版は空の状態から始まります）
